# lam-arabicnumbers

مكتبة Python لتحويل الأرقام إلى كلمات عربية بدقة نحوية.

[![PyPI version](https://badge.fury.io/py/lam-arabicnumbers.svg)](https://pypi.org/project/lam-arabicnumbers/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## المميزات

- ✅ تحويل الأعداد من 0 إلى 20 منزلة
- ✅ المذكر والمؤنث
- ✅ المثنى والجمع والتمييز النحوي
- ✅ العملات (ريال، جنيه، دينار، درهم، دولار)
- ✅ الأعداد الترتيبية (الأول، الحادي والعشرون...)
- ✅ التواريخ (ميلادي وهجري)
- ✅ الوقت (الساعة والدقائق والثواني)
- ✅ الأعداد السالبة
- ✅ بدون أي تبعيات خارجية

## التثبيت

```bash
pip install lam-arabicnumbers
